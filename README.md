# Exercism C++ Solutions

My solutions and learning progress through the Exercism C++ Track.

https://exercism.org/tracks/cpp

This repository is an archive of my C++ learning exercises. Exercises are grouped by the main concept they introduce.

My more substantial algorithm, computer science, and systems programming work lives in separate dedicated repositories.

## Progress

### Basics

- `hello-world` — introduction to the C++ track and workflow
- `lasagna` — variables, functions, arithmetic, and basic C++ syntax

### Namespaces

- `last-will` — namespaces, nested namespaces, and scope resolution

### Strings

- `log-levels` — string processing and standard-library operations

### Control Flow

- `pacman-rules` — booleans and logical operators
- `raindrops` — divisibility, conditional logic, and string construction
